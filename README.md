# 妄想メモリアル (MOSOU-MEMORIAL)

会話していたら、自然に顔がついてくる——姿のないヒロインとの会話から始まる、会話型シミュレーションゲーム。

## コンセプト

- ヒロインは最初、姿を持たない（シルエット）。約10ラリーの会話で好みを聞き取り、**会話の中で**彼女の顔が生まれる
- その後も物語の出来事で同一人物のまま姿が変わっていく（美容院・買い物・加齢・若返り・種族変化…）。変化の判定はチャットLLMが会話全体から行う
- 表情差分（笑顔・照れ・ツン）は無音で裏側生成され、会話に自然に反映される
- 長期記憶: 会話は定期的に要約され、彼女は前の話を覚えている。姿の履歴は「メモリアル」アルバムに残る
- 時間の流れ（日数）と物語の章が、締切やノルマなしに静かに目安を与える
- 邪魔者キャラの乱入、好感度・嫉妬度の駆け引き、ギャグの空気感

設計の核: **しつこくしない／萎える体験をさせない／妄想の中に浸らせる**。仕組みは無音で裏に回し、表に出るのは彼女の台詞と世界観の中の出来事だけ。

## 技術構成

- Next.js 16 / React 19 / Tailwind CSS 4 / Zustand
- 会話: Gemini（構造化出力で返答・好感度・表情・外見変化判定を一括生成）
- 画像: OpenAI gpt-image-2（初回の顔生成＋同一性保持の差分編集）
- 任意: Supabase（セーブ同期・画像ストレージ）。未設定でもローカル保存で動作する

## セットアップ

```bash
pnpm install
cp .env.example .env.local   # キーを記入
pnpm dev
```

必要な環境変数:

| 変数 | 用途 |
|---|---|
| `GEMINI_API_KEY` | 会話生成（必須） |
| `OPENAI_API_KEY` | 画像生成（必須） |
| `NEXT_PUBLIC_SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` | 同期・ストレージ（任意） |

## 公開時の注意

- APIルートにはレート制限と入力上限、年齢ステージの安全ガードが入っている（`docs/public-guards.md`）。本番では共有ストアによる制限とユーザー単位のクォータに置き換えること
- Supabase未設定の場合、生成画像はリロードで消える（base64を永続化しない設計）。公開形態に応じてストレージ設定かBYOK方式を検討すること
