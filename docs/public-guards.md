# 公開ガード（改善7）

公開リリースに向けて、無認証・無制限だったAPIに最低限のガードを入れた。

## レート制限（lib/rate-limit.ts）
AI を叩く全ルートに IP 単位の固定ウィンドウ制限（60秒）:
- `/api/chat`: 30回/分
- `/api/generate-look`: 6回/分（有料画像。誕生+表情で1プレイ数回使う想定の上限）
- `/api/generate-background`: 6回/分
- `/api/memory/summarize`: 10回/分

超過は 429 + Retry-After。**既知の限界**: インメモリなのでサーバーレスのインスタンス単位でしか効かない。乱用への「ブレーキ」であり課金ファイアウォールではない。本番では Vercel KV / Upstash 等の共有ストア＋ユーザー単位クォータに置き換えること（RELEASE_PLAN のBYOK/上限付きβの判断とセット）。

## 入力上限
- チャットの userMessage は 1000 文字まで（超過は 400）

## 年齢ガード（lib/age-guard.ts）
このゲームの画風アンカーは実写寄り（photorealistic）。物語イベントで若返りが起きうるため、未成年ステージの生成は安全側に倒す:
- 検出: attributes.age / extra / changeInstruction に未成年語（子供・小学生・中学生・高校生・幼児・child・high school 等）または 5〜17歳の数値表記
- 倒し方: プロンプトの画風を「健全なイラスト調・非実写・慎ましい服装」に切替え、露出系の服装指定は everyday clothes に置換
- 大人・未指定のステージには一切干渉しない
