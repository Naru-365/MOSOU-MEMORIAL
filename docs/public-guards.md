# 公開ガード（改善7＋Claudeレビュー対応）

公開リリースに向けて、無認証・無制限だったAPIにガードを入れた。Claudeレビュー（C-1〜C-5, M-3〜M-5）を受けて強化済み。

## レート制限（lib/rate-limit.ts）
AI を叩く全ルートに IP 単位の固定ウィンドウ制限（60秒）:
- `/api/chat`: 60回/分
- `/api/generate-look`: 12回/分（通常プレイのバースト＝誕生＋表情＋変化で約3回/分を大きく上回らない範囲で、誤爆コストにはブレーキがかかる値）
- `/api/generate-background`: 8回/分
- `/api/memory/summarize`: 15回/分

超過は 429 + Retry-After。クライアントキーはプラットフォーム設定ヘッダ（x-vercel-forwarded-for）を最優先し、x-forwarded-for は最後尾（最も近いプロキシが付けた値）を使う — 先頭はクライアントが偽装できるため使わない。
**既知の限界**: インメモリなのでサーバーレスのインスタンス単位でしか効かない。乱用への「ブレーキ」であり課金ファイアウォールではない。本番では Vercel KV / Upstash 等の共有ストア＋ユーザー単位クォータに置き換えること（RELEASE_PLAN のBYOK/上限付きβの判断とセット）。
コスト形状の固定（M-4）: generate-look は感情数を最大4種に制限し、size/quality はサーバー側で固定する。クライアント指定は効かない。

## 入力上限
- チャットの userMessage は 1000 文字まで（超過は 400）

## 年齢ガード（多層防御）
このゲームの画風アンカーは実写寄り（photorealistic）。未成年ステージの実写像は公開時の最重要リスクとして、3層で止める:

1. **発生源（C-5）**: チャット/オンボーディングのプロンプトで「ヒロインは常に18歳以上の成人。若返りも成人の範囲内」と固定。`sanitizeLookChange` は未成年ステージへの変化を採用しない（静かに変化なしになる）
2. **検出（C-1/C-3）**: 画像ルートではプロンプトに届く全テキスト（profile含む）を NFKC 正規化して走査。語彙拡張（少女/女子高生/JK/teen/schoolgirl/toddler等、英語は単語境界で childhood friend 等の誤検出を回避）、数値年齢は 0〜17歳・ハイフン形・漢数字・全角まで対応。「15歳若返った」のような差分表現はステージとみなさない
3. **生成経路（C-2/C-4）**: 未成年検出時、編集経路（実写の参照画像あり）は**生成自体を拒否**する（トーン指示では参照の実写感を上書きできないため）。新規生成のみ、自由文フィールドを落とした allowlist 構成＋健全なイラスト調トーンで生成する
