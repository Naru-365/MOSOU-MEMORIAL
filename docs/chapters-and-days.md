# 日数と章（誕生後の目的・区切り）

誕生後のプレイに「目的」と「区切り」を与える仕組み。核（しつこくしない／萎えない／没入）との整合を最優先に設計した。

## 日数
- プレイ25ターン = ゲーム内1日（lib/chapters.ts `DAY_TURNS` / `dayForTurn`）
- 日が変わるとチャットに舞台指示風のノートが1つだけ出る（「―― 2日目のはじまり。」）。ヘッダーにも「◯日目」を表示
- **締切・カウントダウン・期限切れは一切なし**。日が進んでも何も失われない。時間は圧力ではなく天気として流れる
- 各 Look には生まれた日（`Look.day`）が記録され、メモリアルで「3日目 ・ 日付」と読める

## 章
好感度で開く5章（lib/chapters.ts `CHAPTERS`）:
1. 出会いと誕生（誕生時に記録）
2. 肩が触れる距離（好感度30）
3. 特別な存在（55）
4. 心が満ちる日（80）
5. 二人の記念日（100）

- 章が開いたら `Character.chapters` に到達日と一緒に記録し、チャットには静かなノートを1つ（好感度マイルストーンのノートと同ターンで重なる場合はそちらを優先し、二重に出さない）
- メモリアルに「物語の歩み」として到達した章を並べ、プレイ中のキャラには次の章のタイトルだけを「これから」として見せる。**進捗バー・数値条件・報酬は出さない** — 目的は「物語の形」であってクエストではない
- エンディングで強制終了はしない。第5章は到達点であり、関係はそのまま続く（消滅エンドは従来通り好感度0のみ）

## 保存
- `Character.chapters` と `Look.day` はローカル保存（memory と同じ扱い）。クラウド同期への追加は memory 列と合わせて今後のマイグレーション対象
- 旧セーブは chapters なし・day なしでそのまま動く（表示だけ省略される）
