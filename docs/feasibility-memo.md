# 妄想メモリアル 仕様メモ（コンセプト & フィジビリティ）

参考：[ひろちんくん 実況動画](https://youtu.be/hNCNG64ukGw?si=GSDKrbBotCz1VjGg)
ノリの参考：実写×カオス、ギャグ強めで大衆向けに。

## 0. コンセプト（最新）

**テーマ：会話型オープンワールド × 立ち絵会話シミュレーション**

- 「立ち絵で会話するだけ」という一見“縛りの強い”枠に、**生成AIの会話の自由度 ＋ 画像生成の自由度**
  を持ち込み、枠の中の自由を楽しんでもらうのが狙い。
- **実体のない状態から始まる**：最初ヒロインは姿を持たない（立ち絵なし＝シルエット/未確定表示、
  テキストだけ）。
- **会話でキャラメイク**：約 **10ラリー**の会話でユーザーの好み（外見・性格・雰囲気・呼び名）を
  ヒアリング → それを元に **画像生成 → 立ち絵が初めて確定**（＝最初のキャラメイク完成、
  ここで「リファレンス顔」も確定）。
- **見た目は会話の中で動的に変わる**：固定一枚絵ではなく、ワールドの出来事で外見が更新される。
  - 美容院に行けば髪型が変わる
  - 服を買えば衣装が変わる
  - 時間が経てば歳を取る／過去にタイムスリップすれば若返る
  - 「実は犬だった」みたいな飛躍もアリ（種族すら可変）
- **同一人物性 × 可変性の両立**：identity（その子であること）は保ちつつ、髪/服/年齢/種族などの
  属性は**意図的に**変える。これを gpt-image-2 の Edits（リファレンス顔＋差分プロンプト）で実現する。

> 旧コンセプト（恋愛シム＋邪魔者乱入のギャグ）は、この会話型オープンワールドの**中の一要素**として継続。
> 好感度/嫉妬度/邪魔者乱入は、ワールドの“イベント/NPC”的に位置づける。

## 1. 体験フロー

1. **実体なしで会話開始**（立ち絵はシルエット等のフォールバック）。
2. **約10ラリーで好みヒアリング**（外見・性格・呼び名・雰囲気）。
3. ヒアリング結果から**画像生成 → 立ち絵確定**（neutral をリファレンス顔として保存）。
4. 以降は**自由会話**。好感度/嫉妬度が動き、邪魔者が乱入する。
5. **ワールドイベントで外見更新**（美容院/買い物/加齢/タイムスリップ/種族変化…）→
   そのつど `images.edit` で「リファレンス顔＋変更指示」を渡して差分生成。

## 2. ビジュアルのロードマップ

| Phase | 内容 | 採否 |
|---|---|---|
| 1 | gpt-image-2 で「会話ヒアリング → 立ち絵確定 → 表情/外見差分」 | 採用、ここが本線 |
| 2 | 短尺動画ループ | **スキップ寄り**。乱入演出のカットインだけ部分採用は可 |
| 3 | フル3Dヌルヌル（VRM / Three.js + R3F / Ready Player Me） | vibe coding 待ちではなく、現行技術でも踏める |
| 4 | ランタイムでの画像/動画/3D オンザフライ生成（外見変化を逐次生成） | 将来、Responses API のマルチターン編集で |

理由：画像→動画はコスト段差の割に表現幅頭打ち。3Dのほうが枚数あたりの表現力に伸びしろ。
"AIが全部作ってくれる"を待つと永遠に Phase 2 から動けないリスク。
※ 旧 Phase 1 の「実写ストック画像マトリクス（固定 appearance×emotion）」は、外見が動的に変わる
本コンセプトとは前提が合わないため、**事前生成の固定マトリクス → ランタイム寄りの差分生成**へ方針変更。

## 抽象化方針

最初から `<CharacterRenderer mode="image" | "video" | "3d" />` を切っておき、
`getImageUrl` を `getCharacterAsset(character, emotion, mode)` に昇格させる。
フェーズ移行で chat 画面を書き直さずに済む。

外見が動的に変わる本コンセプトでは、解決キーに**「見た目バージョン（lookId）」**を1段足す：
`getCharacterAsset(character, lookId, emotion, mode)`。
- `lookId` = 「会話で確定/更新された外見」のスナップショット（髪型/服/年齢/種族を含む）。
- 美容院・買い物・加齢・タイムスリップなどのイベントで **新しい `lookId` を発行**し、
  その lookId に対して表情差分（emotion）をぶら下げる。
- リファレンス顔は lookId 単位で保持。次の look 生成時は「直前 look を参照画像に渡す」。

## 邪魔者カスタマイズ

- 現状 `InterrupterType` 固定 union → CRUD エンティティに昇格。
- メッセージはテンプレ＋スロット辞書（`{char}` `{user}` `{topic}`）で穴埋め。
- トリガは「閾値 / 周期 / キーワード」の OR で発火させてキャラごとのクセを出す。
- 発展形：Claude API でテンプレ生成→保存。ランタイムはローカル選択でコストは初回のみ。

## ギャグ転換

- 選択肢式は廃止し **自由テキスト会話**を採用済み（Gemini 2.5 Flash）。ボケ/ツッコミ/不条理の
  構造は `affinityChange` の数値ロジックとして内部に残す。
- メタ系邪魔者の第四の壁ネタは継続＋頻度上げ。
- 高 affinity 直球恋愛セリフはフリオチ構造に置換。
- 外見ネタ（実は犬だった等）の**不条理オチ**は、画像生成の飛躍と合わせて見せ場にする。

## データ永続化の注意

- Zustand persist の localStorage 上限（5–10MB）。
- 画像は Base64 直入れ NG、URL を持つか IndexedDB（idb-keyval）へ。
- AI生成採用時は Next.js Route Handler + R2/S3 等の外部保存。
