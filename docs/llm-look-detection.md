# 外見変化のLLM判定（改善6）

## Before
プレイヤーの発言だけをキーワード照合（美容院／服／犬…）。問題:
- 拾えない: 「ボブにして」「イメチェンしたい」「ドレス買ったの」等、語彙の外は全部漏れる
- 誤爆する: 「昔は犬を飼ってて」でも犬化、「いつか髪切りたい」でも切ってしまう
- 彼女のセリフ側の出来事（美容院に行ってきた等）は原理的に拾えない

## After
チャットの応答生成そのものに判定を同梱する。追加のAPIコールなし。
- ヒロインのプレイング応答スキーマに `lookChange` を追加（shouldChange / label / instruction / 変わる属性だけ）
- プロンプトで線引きを明示: 実際に今変わる場合だけ。未来・過去・仮定の話、単なる言及、表情だけの変化は対象外
- サーバーで sanitize（instruction 必須・長さ制限・属性は定義済みフィールドのみ）してから `ChatApiResponse.lookChange` で返す
- 邪魔者ターンでは判定しない（フィールド自体を省く）

## クライアントの使い分け
- `lookChange` が返ってきたらそれが正（null = 変化なし、で確定）
- フィールドが無いターンだけ、従来のキーワード判定にフォールバック

## 既知の限界
- 判定は会話モデルの裁量なので、境界ケースは揺れる。誤爆は有料の画像生成に直結するため、プロンプトは「迷ったら変えない」寄り
- 生まれたて猶予の置換もこの intent に乗る（検出経路が変わっただけで、猶予の仕組みは不変）
